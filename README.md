# Mein Video-Player



# Über das Projekt

Mit der Anwendung können Videos verwaltet und direkt in einer
Benutzeroberfläche abgespielt werden. Außerdem gibt es verschiedene
Steuerungsmöglichkeiten, mit denen sich die Wiedergabe beeinflussen lässt.

Mein Ziel war es, einen eigenen Video-Player zu erstellen und dabei
praktische Erfahrungen in der Webentwicklung zu sammeln.

# Was kann die Anwendung?

- Videos hinzufügen: Neue Videos mit einem Titel und einer URL eintragen.
- Videos auswählen: Zwischen verschiedenen gespeicherten Videos wechseln.
- Videos abspielen: Videos direkt in der Anwendung ansehen.
- Videos löschen: Nicht mehr benötigte Einträge entfernen.
- Wiedergabe steuern: Videos starten und anhalten.
- Video-Navigation: Zwischen den gespeicherten Videos wechseln.
- Regler verwenden: Verschiedene Wiedergabeeinstellungen anpassen.

# Einblick in das Projekt

Im oberen Bereich können Videos über ihren Titel und ihre URL hinzugefügt
oder aus der Liste entfernt werden.

Darunter befindet sich der Videoplayer mit den üblichen Bedienelementen.
Zusätzliche Schaltflächen und Regler ermöglichen eine weitere Steuerung
der Wiedergabe.

# Verwendete Technologien

- HTML
- CSS
- JavaScript
